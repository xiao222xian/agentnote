# 怎么学（学前必读）

## 一、大模型全流程实战

这一阶段是对 **LLM 全流程训练** 的一次掌握，目标是：

> 从 0 到 1 训练出一个大模型，并理解它的每一步后训练过程。

### 学习策略

建议先通过视频资料和图文资料，快速建立“从零训练一个大模型”的完整认知，然后配合实战代码真正跑通一遍。

推荐顺序：

1. 先看视频，建立训练全流程认知
2. 再看 minimind / 相关代码仓库
3. 跟着跑完整流程
4. 最后回头看每个阶段的数据和代码实现细节

---

### 重点推荐：post training 课程

建议重点学习吴恩达的后训练课程。  
这部分对于理解后训练非常关键，重点会讲：

- SFT 的技巧和实战
- DPO 的原理和实现
- 数据、模型、代码如何串起来
- 在线强化学习的基础与实践

---

### 重点实战项目：MiniMind

`minimind` 项目是本阶段最重要的实战载体之一。

优点：

- 完全从 0 开始
- 跑通门槛相对较低
- 最快约 3 小时即可训练出一个约 26M 的微型语言模型
- 能清楚看到 pretrain → sft → dpo → reason → grpo 的全链路

如果机器资源够，也可以继续尝试更大的训练项目，例如 Steel-LLM 之类的方案，但本阶段建议优先把 `minimind` 跑通。

---

### MiniMind 建议跑通的训练流程

推荐你按下面步骤理解和实操：

1. 下载数据集，并放到 `./dataset` 目录
2. 执行 `python train_pretrain.py`  
   得到 `pretrain_*.pth`，作为预训练输出权重
3. 执行 `python train_full_sft.py`  
   得到 `full_sft_*.pth`，作为指令微调输出权重
4. 执行 `python train_dpo.py`  
   完成 DPO 人类偏好对齐
5. 执行 `python train_reason.py`  
   让模型获得初步推理能力
6. 执行 `python train_grpo.py`  
   完成强化学习后训练

---

### 学习要求：不要只把代码跑通

这一阶段尤其强调：

> 不要只把代码跑通，一定要把每一步的代码和数据构造都看懂。

你至少要搞清楚：

- pretrain 数据长什么样
- SFT 数据是怎么组织的
- DPO 的 chosen / rejected 是怎么构造的
- reasoning 数据是什么格式
- GRPO 的 reward 是怎么计算的

### 建议重点学习的内容

1. **Pretrain、SFT、LoRA、RLHF-DPO、reasoning** 这些训练方式分别在解决什么问题
2. 每一种训练方式对应的数据格式是什么
3. 模型的代码实现中，架构如何组织
4. 每一步训练后如何做测试，看效果有没有变化
5. Dense + MoE 架构是怎么写的
6. 蒸馏 SFT、DPO、GRPO 的代码分别长什么样

> 强烈建议：  
> 至少看懂一种训练技术的代码实现，例如蒸馏 SFT / DPO / GRPO 中的一种。

## 二、前瞻技术方向

在完成基础全流程之后，本阶段还安排了两个前瞻方向，目的是帮助你理解：

> 大模型训练正在从“普通后训练”迈向“更复杂的智能体后训练”。

---

### 方向 1：Agentic + RL

这是目前非常新的方向。  
建议从综述和论文开始建立认知：

- 从 LLM-RL 到 Agentic RL
- 从单轮奖励优化到复杂任务过程优化

### 为什么这个方向重要？

因为它让模型不只是“输出一个回答”，而是可以在环境中：

- 自主跳转网页
- 搜索信息
- 整合多源结果
- 完成复杂任务推理
- 通过多步探索得到最终答案

你可以顺带了解这些工作：

- WebWalker
- WebDancer
- WebSailor
- WebShaper
- DeepResearch

最终目的是：

- 理解 WebAgent / DeepResearch 整体框架
- 理解为什么 Agentic RL 会成为一个重要趋势
- 看懂从“普通后训练”到“复杂智能体训练”的变化

---

### 方向 2：RAG + RL

这一部分重点看 **Search-R1**。

资料：

- 论文：  
  https://arxiv.org/abs/2503.09516
- 配套代码：  
  https://github.com/PeterGriffinJin/Search-R1

### 为什么这项工作重要？

它是这一系列中非常有影响力的工作之一，后面衍生了很多：

- R1-Searcher
- R-Searcher
- DeepResearcher
- Mini-Researcher

### 重点理解的问题

你需要思考：

- LLM 学会搜索，是怎么做到的？
- 为什么 RL 可以帮助模型学会自主调用搜索？
- 为什么这类方法能增强持续学习能力？
- 它和传统 RAG 有什么联系和区别？

> 这部分内容非常值得和传统 RAG 结合起来看。  
> 可以理解为：把“检索增强”进一步升级成“搜索驱动的强化学习推理”。

如果有资源和精力，也建议复现一下 Search-R1，它相对是比较容易复现的工作之一。

## 三、资源更充足时的扩展方向

对于资源更充足的同学（例如有 8 卡 A100 或更强资源），建议可选深入两个项目：

### 1. TinyZero

- 项目地址：  
  https://github.com/Jiayi-Pan/TinyZero

这是一个非常热门的项目。  
特点：

- 基于 Qwen2.5-3B
- 包含从 Zero 到推理任务的强化学习训练流程
- 复现 Alpha / DeepSeek-Zero 类后训练技术

学会这个项目后，对于理解：

- DeepSeek 类模型的后训练技术
- Zero-style 强化学习训练
- reward 与 rollout 的关系

会非常有帮助。

---

### 2. DeepAnalyze

- 项目地址：  
  https://github.com/ruc-datalab/DeepAnalyze

这是一个更偏 **RL 智能体** 的项目，可以实现主动编排、优化操作，完成复杂的数据科学任务。

支持的数据核心任务包括：

1. 数据任务：
   - 自动化数据准备
   - 数据分析
   - 数据建模
   - 数据可视化
   - 数据洞察
   - 报告生成

2. 数据研究：
   - 在结构化数据（数据库、CSV、Excel）
   - 半结构化数据（JSON、XML、YAML）
   - 非结构化数据（TXT、Markdown）

中进行开放式深度研究，并生成研究报告。

这个项目非常适合帮助你理解：

- RL Agent 如何在数据环境里工作
- 多步任务规划如何落地
- Deep Agent 的能力边界在哪里
