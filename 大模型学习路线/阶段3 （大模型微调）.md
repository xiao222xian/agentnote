# 怎么学（学前必读）

## 一、微调原理和技术框架

微调阶段会接触多种高阶微调技术。  
本阶段重点掌握两个框架：

- **PEFT**
- **LLaMA-Factory**

同时必须吃透以下参数高效微调方法的原理：

- LoRA
- P-Tuning

对 IA3 等方法做到了解即可。

### 学习建议

#### 第一阶段：先理解原理

先看微调原理视频，建立整体认知，然后重点理解：

- 什么是 SFT
- 什么是参数高效微调
- 为什么 LoRA 有效
- P-Tuning 和 LoRA 的区别
- IA3 的基本思路

#### 第二阶段：跟框架实操跑一遍

框架学习不要求你去啃源码，重点是：

- 会安装
- 会改配置
- 会换模型
- 会换数据
- 会启动训练
- 会看训练日志和结果

### 推荐学习方式

一个比较好的顺序是：

1. 先看框架 README，完成环境安装
2. 然后跑通仓库里给的样例
3. 再看你关心的任务怎么改造成你自己的训练任务

---

### PEFT 学习建议

对于 PEFT 框架，可以参考 Hugging Face 官方 examples，例如：

- `run_peft.sh`
- `run_deepspeed.sh`

理解重点：

- dataset_name 对应的数据格式
- 怎么替换模型
- 怎么切换任务
- 怎么调训练参数

---

### LLaMA-Factory 学习建议

对于 LLaMA-Factory，建议先跑 examples 中的样例，例如：

- `llama3_lora_sft.sh`

重点学习：

- 参数意义
- yaml 配置文件如何组织
- 不同参数如何影响训练

重点关注如下配置：

- `num_train_epochs`
- `learning_rate`
- `warmup_ratio`
- `lora_rank`

如果资源有限，也可以先换成较小模型，例如：

- Qwen2 / Qwen3 小模型

> 这些样例一般更适合在 Linux 环境训练，推荐使用云卡环境，如 AutoDL 租用 4090 进行实验。

---

### PEFT 实操案例说明

PEFT 实操案例中，示例任务是用《甄嬛传》脚本中的对白和语句，基于大模型进行 LoRA 微调，得到一个模仿甄嬛语气的聊天语言模型。

这个例子比较有趣，适合帮助你理解：

- 微调数据怎么构造
- LoRA 是怎么挂到模型上的
- 训练出来的模型如何做特定风格生成

---

### LLaMA-Factory 实操案例说明

LLaMA-Factory 是当前业界用得非常广的微调框架之一，对小白相对更友好。

优点包括：

- 操作简单
- 支持的模型多
- 支持任务丰富
- 配置清晰

建议你把仓库里的例子尽量跑一跑，例如：

- LoRA 微调 LLaMA
- 文本分类微调
- 指令微调

这样你能完整体验从：

- 数据构造
- 模型训练
- 推理评估
- 量化部署

这一整套流程。

## 二、大模型微调项目实战

这一阶段主要做 **两个 NLP 微调任务**，以及一个强化学习微调方向的扩展实践。

### 项目 1：SFT 命名实体识别微调

目标任务：命名实体识别（NER）

重点学习：

- 如果用大模型做 NER，指令数据应该怎么设计
- NER 类任务的数据构造方式
- 如何把分类 / 标注任务转成 SFT 形式
- 怎么设计评估指标

推荐方案：

- 以 **Qwen2-1.5B** 为基座模型
- 使用指令微调方式做命名实体识别

建议重点阅读代码文件，例如：

- `train_qwen2_ner.py`

你需要看懂：

- 数据处理怎么做的
- 输入输出格式怎么设计
- 训练流程是如何组织的

补充说明：

- 案例中使用了 SwanLab 做日志管理和可视化
- 如果你暂时不用，也可以先把相关回调移除
- 完成训练后，要思考如何计算识别指标，后面实战作业会用到

---

### 项目 2：Function Call 微调

目标任务：训练一个会调用工具的大模型

这部分本质是在教会模型：

- 什么时候应该调用 tools
- 应该调用哪一个工具
- 怎么解析工具参数
- 怎么生成符合协议的调用格式

这部分是现在 **Agentic RL** 和工具型模型的基础。

推荐案例使用：

- **GLM-4-9B** 模型进行函数调用能力微调

学习重点：

- Function call 数据是怎么构造的
- Function schema 怎么定义
- 训练后如何测试工具调用效果
- 如何追踪训练过程和结果

该案例提供了：

- 完整文档
- 训练代码
- 数据集
- 结果追踪方法

适合直接跟着跑一遍。

---

### 项目 3：强化学习微调（GRPO）

目标任务：利用强化学习微调，训练一个带有推理能力的数学解题模型。

案例特点：

- 文档中有完整的 agentic RL 实现思路
- 基座模型使用 **Qwen3 0.6B**
- 训练数据采用 `openai/gsm8k`
- 使用 **GRPO** 训练
- 覆盖：
  - 训练
  - 评估
  - 部署

### 重点学习内容

你需要重点理解：

1. 训练数据是如何构造的
2. 微调指令是如何构造的
3. reward 函数如何设计
   - 格式正确性
   - 答案正确性
4. 模型分布式训练是怎么做的

学完后，你应该知道如何从 0 到 1 用强化学习训练一个具备推理能力的数学模型。

### 延伸建议

- 阅读 GRPOTrainer 源码
- 看 `GRPO From Scratch`
- 理解完整的“从原理到代码”链路
