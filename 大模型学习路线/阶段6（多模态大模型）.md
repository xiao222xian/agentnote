# 怎么学（学前必读）

## 一、多模态核心原理

现在大模型岗位里，多模态已经是非常重要的方向。  
在实际面试中，也很可能会被问到多模态基础问题。

虽然模态变了，但现在很多多模态模型的底座仍然是 **Transformer**。  
所以这一阶段的目标是：

> 用你已经掌握的 Transformer 基础，去理解图像、文本、图文对齐和图像生成这些新能力是如何长出来的。

### 学习顺序建议

建议按下面顺序学习：

1. **Vision Transformer（ViT）**
2. **CLIP**
3. **扩散模型**
4. **Stable Diffusion**

---

### 1）先学 ViT

ViT 是多模态学习最基础的入口之一。  
你需要重点理解：

- 图像如何切成 patch
- patch 如何转成 token
- 图像 token 和文本 token 在表示形式上有什么差异
- ViT 在原始 Transformer 结构上做了什么修改

建议不要只看理论，最好找一些输入图片自己跑一跑代码，直观理解图像是如何被编码的。

---

### 2）再学 CLIP

CLIP 是多模态图文对齐领域的里程碑工作，可以视为 OpenAI 早期多模态路线的奠基模型。

你需要重点理解：

- 图像编码器和文本编码器怎么配合
- 图文对比学习是怎么做的
- 正负样本的构造逻辑
- 为什么 CLIP 对后续多模态模型影响这么大

重点不是背论文，而是要能讲清楚：

> CLIP 为什么能把图和文映射到同一个语义空间。

---

### 3）再学扩散模型

扩散模型是当前 AIGC 文生图、图生图、文生视频等任务最核心的底层技术之一。

学习建议分两层：

#### 基础层
如果数学基础一般，可以先看通俗版，理解宏观原理：

- 扩散
- 加噪
- 去噪
- 训练目标

#### 深入层
如果基础较好，可以进一步学习：

- 公式推导
- 采样过程
- 反向去噪链条
- 代码实现

建议把扩散模型配套代码跑一遍，理解：

- 训练过程在做什么
- 采样过程在做什么
- 模型最终是如何生成图像的

---

### 4）最后学 Stable Diffusion

Stable Diffusion 是文生图里非常经典的开源路线。

前面的扩散模型更多偏无条件生成，这一部分要重点理解：

- 条件生成
- 文本条件如何注入
- latent diffusion 的意义
- UNet 在其中扮演什么角色

如果有兴趣，也可以自己下载一个公开模型试玩，例如：

- `stable-diffusion-3-medium`

目的是感受从原理到实际效果之间的连接。

---

## 二、多模态大模型

这一部分主要掌握三块内容：

1. 多模态模型的整体理解
2. 全模态 / Omni 模型
3. 多模态推理

---

### 1）先学 Qwen-VL 系列

建议把 **Qwen-VL 系列** 作为主线。

原因：

- 社区活跃
- 效果稳定
- 中文生态好
- 技术资料相对全
- 微调、推理部署、强化学习都有资料

通过这一系列内容，建议你至少搞清楚：

- 多模态数据是怎么构造的
- 图像特征如何接入大模型
- 模型结构如何组织
- 多模态训练流程是什么
- 各代模型的改进点在哪里
- 多模态微调是怎么做的

---

### 2）补充了解其他架构

在 Qwen-VL 之外，也建议了解一些其他代表架构作为补充，例如：

- MiniCPM
- DeepSeekOCR

这样可以帮助你建立对不同多模态路线的认识，避免只懂单一路线。

---

### 3）理解全模态 / Omni

Omni 模型的核心，是让模型可以同时处理：

- 文本
- 图像
- 音频
- 视频

你需要重点理解：

- 什么叫全模态
- 模态之间是如何统一建模的
- 为什么 Omni 比传统 VLM 难得多
- Qwen-omni 这类模型在工程上意味着什么

---

### 4）理解多模态推理

这一部分是近一年研究热点，也可以理解为：

> 从 DeepSeek-R1 的文本推理，扩展到图像推理、多模态推理。

推荐重点看：

- VLM-R1
- 相关论文、讲解和代码

这部分你需要知道：

- 多模态推理为什么比文本推理更难
- 如何把 GRPO / SFT 这些训练方式迁移到 VLM 上
- 图像信息参与推理时，reward / answer format / data format 会发生什么变化

如果资源不足，可以先把原理搞懂，不强求完全复现。

---

## 三、多模态评测

这一部分主要是作为算法 / 测试 / 选型层面的补充知识。

你至少要掌握两个主流评测：

- MMMU
- MMBench

### 学习目标

你需要知道：

- 多模态模型通常怎么评测
- 不同 benchmark 在测什么
- 榜单代表了什么
- 如果要看某个多模态模型的公开表现，去哪里查

### 实操建议

建议亲手做一轮基础评测。  
例如使用：

- `Qwen/Qwen3-VL-8B-Instruct`

并用官方代码跑一下 MMMU 流程，感受一下：

- 数据格式
- 推理方式
- 指标计算
- 最终成绩汇总

这样你就会知道，换成别的多模态模型时流程其实是类似的。

### 1）从 0 到 1 训练一个多模态模型

推荐项目：

- `minimind-v`

这是一个低资源也能完整跑通的项目，适合帮助你走完：

- 数据构建
- 预训练
- SFT 监督微调
- 推理测试

这个项目可以视作一个类 LLaVA 路线的实践版本。

#### 数据说明

案例里使用的数据集例如：

- chinese-LLaVA-Vision

- 约 14 万张图片
- 约 30 万条指令数据

学习重点：

- 每个阶段数据集是怎么构造的
- 多模态样本是怎样被 processor 处理的

- 训练流程如何组织

如果资源更充足（例如 8 卡 A100+），也可以进一步看：

- LLaVA-NEXT
- MiniGPT-4

学习要求：

### 3）多模态 VLA（拓展）

如果你对机器人、自动驾驶、具身智能方向感兴趣，可以继续看 **VLA**。

VLA = Vision + Language + Action

它让模型不只是“看图说话”，而是要做到：

- 感知环境
- 理解指令
- 决策动作
- 控制机器人执行

推荐项目：

- NVIDIA Isaac GR00T

这个方向现在在：

- 机器人
- 自动驾驶
- 具身智能系统

中都很热。

学习目标不是让你现在就完整复现，而是知道：

- 多模态为什么会继续往 action 扩展
- VLA 比传统 VLM 多了什么
- 视觉-语言-动作统一建模意味着什么

# 实战作业

## 作业目标

基于 **VLM + LLM** 完成一个 **出题系统**。

### 任务描述

输入是一张 **文献截图 / 资料截图**，请根据这张截图：

1. 生成 **10 道题目**
2. 为每道题生成对应 **参考答案**
3. 为每道题打一个 **质量分（1 ~ 5）**
4. 每道题都以 **JSON 格式** 输出

---

## 关键要求

- 图片理解必须使用 **多模态大模型**
- 使用模型不限
- **多模态必须使用本地化模型**
- **不能使用接口**
- 文本整理 / 二次组织可以配合文本大模型完成

---

## 数据集

- 形式：刑法案例截图

---

## 输出格式要求

共输出 10 道试题 QA。  
每一道题都必须包含：

- `question`
- `answer`
- `score`
- `reason`

### 示例 1

```json
{
  "question": "刑法第十一条是什么",
  "answer": "外交代表刑事管辖豁免",
  "score": 2,
  "reason": "问题较简单，考察维度比较单一。"
}
````

### 示例 2

```json
{
  "question": "过失犯罪和故意犯罪最本质的区别是什么",
  "answer": "故意犯罪的行为人是明知并希望或放任犯罪结果的发生，而过失犯罪的行为人是不认识或对可能发生的危害结果不抱希望，只是因疏忽大意或过分自信而导致犯罪结果的发生。",
  "score": 4,
  "reason": "问题综合，需要一定的理解和推理能力。"
}
```

# 其他注意事项

1. 本阶段不要把多模态看成“另一个完全不同的世界”，它本质仍然建立在 Transformer 与对齐训练基础上。
2. 多模态学习里，视觉编码、图文对齐、扩散生成、推理增强，是四条主线。
3. 不要求你把所有图像生成、视频生成模型都跑通，但至少要真正理解一条路线。
4. 多模态项目里，数据格式、processor、视觉 token、对齐方式，都是面试高频点。
5. 做作业时要注意区分：

   * 图片 OCR
   * 图片理解
   * 多模态推理
     这三者不是一回事。
6. 如果资源有限，优先完成本地小模型推理 + 结果整理，不强求大模型复现。
